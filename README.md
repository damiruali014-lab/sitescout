# SiteScout

Find small businesses that need a website → check their site → score the lead → generate a demo landing page and a personal outreach message → track the conversation.

Built by [Damir Uali](https://damiruali014-lab.github.io). See [BUILD_LOG.md](./BUILD_LOG.md) for how it was built.

## Quick start
```bash
npm install
cp .env.example .env.local   # optional — without keys the app runs in Demo mode
npm run dev
```
(Full setup and deploy guide is added in the final step.)
